Política de Privacidade

PersonalVS — última atualização: 22 de julho de 2026
⚠️ Este documento é um modelo funcional, redigido para refletir com clareza o que este app faz na prática. Não substitui uma revisão por um profissional jurídico, especialmente por envolver dados sensíveis de saúde/treino.

1. Quem somos

O PersonalVS é um aplicativo de gestão para profissionais de educação física (personal trainers), que permite cadastrar e acompanhar os próprios alunos.

2. Quais dados coletamos

Do profissional que cria a conta: nome, e-mail e senha (a senha nunca é armazenada em texto puro — apenas um hash criptográfico dela).

Dos alunos cadastrados dentro do app: nome, contato, frequência, agenda de treinos, observações e, dependendo do uso que o profissional fizer do app, informações relacionadas a objetivos físicos, alimentação ou restrições — dados que a LGPD trata como dados sensíveis (de saúde) quando aplicável.

3. Por que coletamos

Exclusivamente para permitir que o profissional organize sua própria rotina de trabalho: controle de presença, agenda, planos de treino e comunicação com seus alunos. Não usamos esses dados para nenhuma outra finalidade.

4. Quem é responsável pelos dados dos alunos

Os alunos não criam conta nem interagem diretamente com o app — quem insere os dados deles é o profissional. Por isso, o profissional é o responsável (controlador) pelos dados dos próprios alunos e deve ter a autorização deles para registrar essas informações aqui. O app atua como ferramenta (operador) que armazena esses dados com segurança, isolados por conta.

5. Como protegemos os dados

  • Cada conta só enxerga os próprios dados — isolamento reforçado no banco de dados (Row Level Security), não apenas na tela.
  • Toda comunicação entre o app e o servidor é criptografada (HTTPS).
  • Senhas nunca são armazenadas em texto puro.
  • Os dados ficam hospedados em servidores no Brasil (região São Paulo).

6. Compartilhamento com terceiros

Não vendemos nem compartilhamos dados com terceiros para fins comerciais. Os dados trafegam apenas pelos provedores de infraestrutura necessários para o app funcionar (banco de dados e envio de e-mails transacionais, como recuperação de senha).

7. Retenção e exclusão

O profissional pode excluir a própria conta a qualquer momento, direto no app (tela "Conta"). Isso apaga permanentemente o login e todos os dados associados — inclusive os dos alunos cadastrados por ele — de forma irreversível.

8. Armazenamento local no aparelho

O app guarda uma cópia dos dados no armazenamento local do navegador, para funcionar mesmo momentaneamente offline. Isso não é um cookie de rastreamento — é só uma cópia técnica, apagada ao excluir a conta ou os dados do navegador.

9. Direitos do titular dos dados

Você pode solicitar acesso, correção ou exclusão dos seus dados a qualquer momento pelo canal de contato abaixo. Se você é aluno de um profissional que usa este app e quer exercer esses direitos, procure diretamente o profissional responsável pelo seu cadastro — ele é quem administra essa informação.

10. Alterações nesta política

Podemos atualizar este documento conforme o app evolui. A data no topo desta página sempre indica a versão mais recente.

11. Contato

Dúvidas ou solicitações sobre seus dados: contato@personalvs.app (substitua pelo e-mail de contato real)
